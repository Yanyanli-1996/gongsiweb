## 不能归并的易混项

| A | B | 区别 |
|---|---|---|
| E0级板材 | ENF级板材 | 国标等级不同：ENF 甲醛≤0.025mg/m³，比 E0（≤0.050）严格一倍 |
| 头层牛皮 | 半青皮 | 头层修饰完整纹理细腻；半青皮保留天然毛孔、修饰更少 |
| 科技皮 | 科技布 | 科技皮是仿真皮（人造革）；科技布是布面有微绒 |
| 真皮 | PU皮 | 真皮是天然牛皮；PU皮是人造革 |
| 实木 | 各种木种 | 橡木/黑胡桃木/白蜡木/水曲柳/榉木/楸木/松木/橡胶木 是具体木种，「实木」只是泛称 |
